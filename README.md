# 不動産積算ナビ — Chrome拡張

投資用不動産の**積算評価・民泊転用可能性・融資評価・出口戦略**を
ブラウザで物件を見ながら高速判断できるChrome拡張機能です。

---

## 機能一覧

| 機能 | 内容 |
|------|------|
| 半自動物件抽出 | 楽待・健美家・SUUMO等のページからユーザー確認後に情報取得 |
| 積算価格計算 | 路線価×補正率（奥行・間口・旗竿・再建築不可等）＋建物残存価値 |
| 民泊転用評価 | 用途地域・駅距離・観光需要・法的適性をスコア化 |
| 融資評価 | 積算比率・担保余力・地銀/信金/ノンバンク適性を概算判定 |
| 出口戦略評価 | 実需/投資家/民泊/更地/建替えの各出口をスコア化 |
| 総合スコア | S/A/B/C/D グレードで投資判断をサポート |
| 比較一覧 | 複数物件を登録してランキング比較 |
| TSV/CSV/JSON出力 | Google Sheetsへ貼り付け最適化 |
| ステータス管理 | 買付候補・詳細確認・保留・除外 |
| 外部リンク生成 | 国税庁路線価・Google Maps・ハザードマップ等を住所から生成 |

## セットアップ

### 前提条件

- Node.js 18以上
- npm 9以上
- Google Chrome 114以上（サイドパネルAPI対応）

### インストール

```bash
# リポジトリをクローン
git clone <repo-url>
cd realestate-sekisan

# 依存パッケージインストール
npm install
```

### ビルド

```bash
npm run build
```

`dist/` ディレクトリにChrome拡張ファイルが生成されます。

### テスト実行

```bash
npm test
```

### 開発モード（ウォッチ）

```bash
npm run build:watch
```

## Chrome拡張のインストール方法

1. `npm run build` を実行して `dist/` を生成
2. Chromeを開く → アドレスバーに `chrome://extensions/` と入力
3. 右上の「デベロッパーモード」をONにする
4. 「パッケージ化されていない拡張機能を読み込む」をクリック
5. `dist/` フォルダを選択
6. 拡張機能アイコンが表示されれば完了

## 使い方

1. 楽待・健美家・SUUMO等で投資物件のページを開く
2. Chrome右上の**不動産積算ナビ**アイコンをクリック
3. 「このページから物件情報を取得」ボタンを押す
4. 取得候補を確認して「保存してサイドパネルへ」
5. サイドパネルで積算タブを開き、**路線価**を入力して計算
6. 民泊・融資・出口タブで各評価を確認
7. 一覧タブでTSVコピー → Google Sheetsに貼り付け

## 積算計算ロジック

### 土地積算

```
土地積算価格 = 路線価 × 土地面積 × 各種補正率の積

補正項目:
- 奥行価格補正（国税庁基準）
- 間口狭小補正
- 不整形地補正
- 旗竿地補正 (×0.85)
- 再建築不可補正 (×0.60)
- セットバック補正 (×0.97)
- 2面接道プレミアム (×1.03)
- 借地権割合
```

### 建物積算

```
建物積算価格 = 再調達単価 × 建物面積 × 残存価値率

残存価値率 = max(0.1, 1 - 経過年数 / 法定耐用年数)

法定耐用年数:
- 木造: 22年 / 軽量鉄骨: 19年(or 27年) / 重量鉄骨: 34年
- RC: 47年 / SRC: 47年

再調達単価（デフォルト）:
- 木造: 18万円/㎡ / 軽量鉄骨: 20万円/㎡ / 重量鉄骨: 23万円/㎡
- RC: 27万円/㎡ / SRC: 30万円/㎡
```

## 禁止事項（設計方針）

- ログイン突破・認証回避
- 利用規約違反となるスクレイピング
- 大量・自動巡回
- 有料機能の模倣・コピー
- サーバへの負荷攻撃

本ツールは「ユーザーが閲覧しているページ」から  
**ユーザー操作で候補値を抽出する補助ツール**として設計されています。
